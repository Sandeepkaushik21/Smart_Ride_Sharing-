📧 3. Email Notifications Triggered
Trigger Event Email Method Recipient Description
📋 Booking Created sendBookingConfirmation() 🧑 Passenger Confirmation with ride details — source, destination, date & time
📋 Booking Created sendRideBookingNotification() 🚗 Driver Notifies driver a new passenger has booked their ride
✅ Driver Accepts sendDriverAcceptanceNotification() 🧑 Passenger Acceptance notice with fare amount — prompts payment
❌ Passenger Cancels sendBookingCancellationNotification() 🚗 Driver Informs driver the booking was cancelled
❌ Driver Cancels Ride sendRideCancellationNotification() 🧑 Passenger Cancellation + reason. Refund processed if payment was made
🔄 Ride Rescheduled sendRideRescheduleNotification() 🧑 Passenger New date/time, reason, and request to accept or cancel
🔄 Reschedule Refund sendRescheduleRefundNotification() 🚗 Driver Notifies driver that refunds were issued to passengers
⏰ Ride Reminder sendRideReminderNotification() 🧑 Passenger Automated reminder X hours before departure
🚗 Ride Posted sendRidePostedNotification() 🚗 Driver Confirmation that the ride has been published successfully
🛡️ Driver Approval sendDriverApprovalNotification() 🚗 Driver Admin approves or rejects driver registration
🔑 Temp Credentials sendTempCredentials() 👥 User Temporary password sent on registration
🔑 Forgot Password sendForgotPasswordEmail() 👥 User Temporary password reset email
